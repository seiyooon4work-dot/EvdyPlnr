# 하루기록

매일의 한 일, 할 일, 식단을 한 페이지에 기록하는 모바일 우선 플래너입니다.

## 사용하기

- `오늘`: 날짜를 넘겨가며 한 일·할 일·식단을 기록합니다.
- `달력`: 기록이 있는 날과 완료한 할 일을 한눈에 봅니다.
- `기록 돌아보기`: 최근 7일의 기록 리듬을 가볍게 확인합니다.
- `데이터 백업`: JSON 파일로 기록을 내보내거나 다른 기기에서 가져옵니다.

다음 확장 항목으로는 하루를 짧게 돌아보는 `오늘 평가`를 추가할 수 있도록 기록 구조에 자리를 남겨두었습니다.

기록은 로그인 없이 브라우저의 기기 저장소에 보관됩니다. 따라서 휴대폰·아이패드·맥 사이에서 자동 동기화되지는 않으며, `데이터 백업`의 내보내기/가져오기를 사용하면 기록을 옮길 수 있습니다.

## GitHub Pages

이 프로젝트는 빌드 과정이 없는 정적 PWA입니다. GitHub Pages에서 저장소의 `main` 브랜치와 루트 폴더를 배포 대상으로 지정하면 바로 사용할 수 있습니다. `manifest.webmanifest`와 서비스 워커가 포함되어 있어 모바일 브라우저의 홈 화면에도 추가할 수 있습니다.
