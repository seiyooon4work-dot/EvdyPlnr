# 하루기록 iPhone 앱

웹 플래너에서 적은 항목을 애플 캘린더와 미리 알림으로 보내고, 마지막으로 보낸 항목을 홈 화면 위젯에 보여주는 첫 번째 네이티브 버전입니다.

## Xcode에서 실행하기

1. `DayListNative.xcodeproj`를 Xcode로 엽니다.
2. 왼쪽 프로젝트에서 `DayListNative` 타깃을 선택하고 `Signing & Capabilities`에서 본인의 Apple 계정을 `Team`으로 선택합니다.
3. `DayListWidget` 타깃에도 같은 `Team`을 선택합니다.
4. 두 타깃의 App Groups에 `group.com.seiyooon4work.daylist`가 들어 있는지 확인합니다.
5. 아이폰을 연결하고 실행 기기로 선택한 뒤 Run을 누릅니다.

## 사용 방법

- 항목과 시간을 입력합니다.
- `캘린더에 추가` 또는 `미리 알림에 추가`를 누릅니다.
- 처음 누를 때 각 앱의 권한을 허용합니다.
- 홈 화면에서 `하루기록` 위젯을 추가하면 마지막으로 보낸 항목이 표시됩니다.

현재 버전은 네이티브 앱에서 애플 앱으로 보내는 1차 연동입니다. 기존 웹 플래너의 localStorage 기록을 아이폰 앱과 자동으로 합치는 양방향 동기화는 별도의 로그인·동기화 서버를 붙이는 다음 단계로 남겨두었습니다.
